# 철강 실무 일본어 트레이닝

포스코 수출팀이 일본계 자동차사·철강사를 상대할 때 실제로 쓰는 일본어를 하루 20분 분량으로 훈련하는 웹 앱과, 그 자료를 만드는 스킬입니다.

## 바로 쓰기

`dist/철강일본어_트레이닝.html` 파일을 내려받아 더블클릭하면 브라우저에서 열립니다. 설치할 것도, 인터넷 연결도 필요 없습니다.

## 하루 구성 (20분)

| | 절 | 내용 |
|---|---|---|
| 📌 | 오늘의 용어 | 8개. 카드를 눌러 뜻 확인, 🔊로 발음 확인 |
| 💬 | 실무 예문 | 8개. **용어 하나당 예문 하나**, 형광펜으로 표시 |
| 📰 | 기사 독해 | 일본 업계 기사 1단락. 문장별 해석 + 표현표 |
| 🤝 | 상담 회화 | 8턴. 그날 용어가 다시 등장 |
| 🎯 | 확인 퀴즈 | 6문항. 객관식 자동 채점 |
| ⭐ | 오늘의 한 줄 | 외워서 내일 쓸 문장 |

### 수준 조절

화면 위 스위치로 **후리가나**와 **해석**을 각각 끌 수 있습니다. 둘 다 끄면 실전 난이도가 되므로, 초급자와 중급자가 같은 자료를 쓸 수 있습니다.

### 진도

🏠 내 진도 화면에서 연속 학습 일수, 완료 일차, 퀴즈 정답률, 익힌 용어 수를 볼 수 있습니다. 진도는 **각자 브라우저에만 저장**되며 서버로 전송되지 않습니다. `진도 요약 만들기` 버튼으로 텍스트를 뽑아 팀에 공유할 수 있습니다.

## 수록 현황

| 일차 | 주제 | 기사 지문 |
|---|---|---|
| 1 | 가격·계약 | 실제 보도 (닛케이) |
| 2 | 제품·규격 | 학습용 예시 |
| 3 | 납기·물류 | 학습용 예시 |
| 4 | 품질·클레임 | 학습용 예시 |
| 5 | 업계 동향 | 실제 자료 (일본철강연맹·일간철강신문) |

목표는 30일치입니다. 주 단위로 추가합니다.

> 기사 지문은 **실제 보도**와 **학습용 예시**를 화면에서 딱지로 구분합니다. 학습용 지문은 회사명을 일반화하고 수치를 특정 기업 정보로 쓰지 않습니다.

## 자료 만들기

`skill/` 폴더는 이 자료를 만드는 Claude Code 스킬입니다. `~/.claude/skills/steel-japanese-drill/`에 넣으면 "오늘 일본어 자료 만들어줘" 한마디로 새 일차를 만들 수 있습니다.

- `skill/SKILL.md` — 구성 규칙과 검증 절차
- `skill/references/glossary.md` — 철강·자동차 조달 용어집
- `skill/references/business-japanese.md` — 상담·메일 정형표현, 완곡어법

### 품질 기준

자료는 다섯 시각의 검증을 모두 통과해야 합니다. 각 항목 10점 만점에 **9.5점 이상**이어야 내보냅니다.

1. **업계** — 실제 업계에서 쓰는 말인가
2. **어학** — 초급을 중급으로 끌어올리는가
3. **일관성** — 용어와 예문이 1:1인가, 표현표가 지문과 맞는가
4. **학습자** — 3년차 사원이 매일 열 만한가
5. **디자인** — 보고 싶어지는 화면인가

## 다시 빌드하기

내용을 고친 뒤 다시 만들려면 `app/app-template.html`을 편집하고 아래를 실행합니다. 글꼴을 base64로 심어 단일 HTML 파일을 만듭니다.

```powershell
powershell -ExecutionPolicy Bypass -File app/build.ps1
```

## 발음 듣기

브라우저 내장 음성 기능을 씁니다. 외부로 나가는 통신이 없습니다.

**일본어 음성이 없으면 소리가 나지 않습니다.** 한국어 Windows에는 기본 설치되어 있지 않습니다.

- **Windows** — 설정 → 시간 및 언어 → 언어 및 지역 → 언어 추가 → 日本語 → 설치 시 **음성** 항목 체크
- **아이폰** — 대부분 기본 지원
- **안드로이드** — 설정에서 Google 음성 서비스의 일본어 다운로드
